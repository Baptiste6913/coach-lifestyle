# Notes complémentaires

## Pyramidal sur compounds (3 premiers exercices de chaque séance)

Schéma de charge pour les sets 1, 2, 3 :
- **Set 1** : 70 % de la charge de travail
- **Set 2** : 85 % de la charge de travail
- **Set 3** : 100 % (charge de travail, échec proche)

Les isolations et supersets sont à **charge constante** (3 sets identiques, échec 0-1 RIR).

## Échauffement spécifique par exercice

Chaque compound prévoit un échauffement chiffré avant les 3 sets pyramidaux :

- **Tirage vertical prise neutre** : barre vide ×10, puis 50 % ×6 (contraction scapula)
- **Rowing Hammer Strength unilatéral** : 1 série légère (tirer avec le coude)
- **Tirage horizontal câble** : 1 série légère (contraction pic 1 sec)
- **Développé couché haltères** : 2 séries (barre vide → 50 %), contrôle descente
- **Développé militaire Hammer** : 1 série à 50 % (ne pas verrouiller violemment)
- **Dips lestés** : 1 série au poids du corps, inclinaison avant pour cibler pecs
- **Tractions lestées** : 2 séries (assisté max → charge intermédiaire)
- **Rowing barre T** : 1 série légère, buste à 45°
- **Pullover câble corde** : 1 série légère, étirement lats en haut
- **Développé couché incliné barre** : 2 séries (barre vide → 50 %), inclinaison 30°
- **Développé épaules haltères assis** : 1 série légère, dos collé au banc
- **Écarté poulie haute** : 1 série légère, croiser légèrement en bas

## Cues d'exécution importants

- **Pec Deck** : charge constante, contraction pic 1 sec
- **Élévations latérales haltères** : charge qui fait échouer à 12-15, coudes légèrement fléchis
- **Extensions triceps corde** : coudes verrouillés contre les flancs
- **Élévations latérales câble (1 bras)** : amplitude complète, ne pas basculer le buste
- **Pushdown barre V** : contraction en bas 1 sec
- **Curl barre EZ** : charge constante, 1 RIR
- **Face Pulls (Pull A & B)** : coudes hauts, rotation externe à la fin
- **Curl incliné haltères** : bras en extension complète en bas
- **Rear Delt Fly** : coudes légèrement fléchis, squeeze arrière
- **High Cable Curls** : 2 poulies hautes, contraction au milieu
- **Curl marteau corde** : focus brachial + brachio-radial
- **Cable Crunches (à genoux)** : flexion colonne complète, hanches fixes

## Substitutions possibles (Fitness Park République)

Substitutions déjà encodées dans les noms d'exercices du programme :
- **Tractions lestées** → **Tractions assistées** (si charge propre insuffisante)
- **Dips lestés** → **Dips machine** (si pas de ceinture lestée ou pour cibler pecs avec inclinaison)

Substitutions plausibles selon disponibilité réelle de la salle (non explicitement encodées) :
- **Rowing Hammer Strength unilatéral** → Rowing Technogym sélectorisé ou rowing barre haltère un bras (si Hammer indisponible ce jour-là)
- **Développé militaire Hammer Strength** → Développé épaules Technogym (machine assise)
- **Rowing barre T** → Rowing T avec barre olympique en coin de mur ou rowing pendlay (si pas de support T-bar)

## Structure des supersets antagonistes

Identifiant `A` = SS1 (première paire), identifiant `B` = SS2 (deuxième paire).

Règle de protocole : **15 s de repos entre les deux exercices** de la paire, puis **90 s après la paire complète** avant de répéter.

Paires v7 :
- **Pull A** — A : Curl EZ + Face Pulls (biceps + rear delt) ; B : Curl incliné + Rear Delt Fly (biceps + rear delt)
- **Push A** — A : Élév latérales haltères + Extensions triceps corde (deltoïde latéral + triceps) ; B : Élév latérales câble + Pushdown V (deltoïde latéral + triceps)
- **Pull B** — A : High Cable Curls + Face Pulls (biceps + rear delt) ; **B : voir ambiguïté ci-dessous**
- **Push B** — A : Élév latérales machine + Skull Crushers (deltoïde latéral + triceps) ; B : Élév frontales + Dips machine triceps (deltoïde antérieur + triceps)

# ⚠️ Points à valider avant import

## 1. Pull B : ambiguïté sur SS2 (Curl marteau + Cable Crunches)

Dans le code source v7, **Curl marteau corde** est étiqueté `SS2a` (donc censé faire partie d'une paire), mais son partenaire `SS2b` n'apparaît pas. **Cable Crunches** suit immédiatement, marqué comme isolation standalone (rest 75 s, pas de tag SS).

Trois interprétations possibles :
- **(a)** v7 a brisé volontairement la paire SS2 de v6 (qui appariait Curl marteau + Cable Crunches en violation de la règle "antagonistes uniquement", biceps + abdo n'étant pas antagonistes) → les deux sont standalone en v7
- **(b)** Erreur d'encodage : Cable Crunches aurait dû rester en SS2b
- **(c)** Curl marteau doit être appairé avec autre chose et Cable Crunches déplacé

**Choix actuel dans le tableau ci-dessus** : interprétation (a), les deux en standalone avec `Superset: null`. C'est l'option la plus cohérente avec la règle "supersets antagonistes uniquement". **À confirmer.**

## 2. Push B : Écarté poulie haute classé "compound"

Biomécaniquement, l'écarté poulie haute est une isolation (mono-articulaire pec). Mais en v7 il est l'un des 3 exercices d'ouverture traités avec le pyramidal 70/85/100 %. Suivant ta règle de classification (compound = les 3 exos d'ouverture pyramidaux), il est marqué `compound: true` dans le tableau. **Si ton dashboard distingue compound/isolation sur critère biomécanique, il faudra l'overrider en "isolation pyramidée".**

## 3. Décompte total des sets par session

Mémoire projet annonce 18/18/18/16 sets pour Pull A / Push A / Pull B / Push B. Décompte exact par exercice ci-dessus :
- **Pull A** : 7 exos × 3 = 21 sets
- **Push A** : 8 exos × 3 = 24 sets
- **Pull B** : 7 exos × 3 = 21 sets
- **Push B** : 5 exos × 3 + 2 exos × 2 = 19 sets

L'écart vient probablement d'une convention de comptage spécifique au programme (peut-être les sets pyramidaux 70 % et 85 % comptent comme échauffement et non comme "working sets"). **À clarifier si ton dashboard a besoin d'une métrique de volume cohérente.**

## 4. Tempo

**Aucun tempo n'est explicitement codé** dans le programme v7 (ex : 3-1-1, 4-0-X, etc.). Les seules notes d'exécution temporelles sont qualitatives : "contrôle descente", "contraction pic 1 sec", "contraction en bas 1 sec". À encoder en tempo formel si ton dashboard l'exige (suggestion par défaut : 2-1-1 sur compounds, 2-1-1 avec pause haute 1 sec sur les exos qui le notent).

## 5. RIR / intensité cible

Notes du programme :
- **Compounds (set 3 à 100 %)** : échec proche, ~1 RIR
- **Isolations standalone** : échec 0 RIR
- **Supersets** : 1 RIR sur SS1, échec 0 RIR sur SS2 (variable selon l'énergie)

Si ton dashboard tracke le RIR par exercice, il faut l'ajouter colonne par colonne.
